## What it is

HTML stands for HyperText Markup Language. It describes the structure
of a web page using elements such as headings, paragraphs, links, and
forms.

## Why it matters

A browser uses HTML to understand and display the content of a page.
Clear structure also helps people navigate with assistive technology.

## Example

```html
<h1>Welcome to my playbook</h1>
<p>This is my first entry.</p>
```

## Security connection

HTML provides the structure of a page, but an application also needs
to handle user input safely. We’ll expand on that as we study forms and
web application vulnerabilities.
